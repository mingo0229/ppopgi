# 뽑기 통장

인형뽑기 횟수를 세어 주는 작은 웹앱입니다. 주소로 바로 열 수 있고, 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

주소: https://mingo0229.github.io/ppopgi/

## 규칙

- 매달 1일에 30회로 시작하고, 뽑기 한 판(1,000원)마다 1회가 줄어듭니다.
- 인형을 뽑으면 작은 인형은 3회, 큰 인형은 6회를 돌려받습니다. 이번 달 남은 횟수와 오늘·이번 주·1시간 횟수에 모두 더해집니다.
- 기본 횟수는 하루 10회, 일주일(월~일) 15회, 1시간에 8회입니다.

## 인형 그림 바꾸기

앱 아래쪽의 "인형 그림"에서 휴대폰에 저장된 그림을 고르면, 유리 상자에 쌓이는 인형이 그 그림으로 바뀝니다(최대 8장, 뽑을 때마다 차례로 나옵니다).
고른 그림은 그 휴대폰 안에만 저장되고, 이 저장소나 인터넷 어디에도 올라가지 않습니다.

## 휴대폰에 설치하기

- 아이폰: Safari로 주소 열기 → 공유 버튼 → "홈 화면에 추가"
- 안드로이드: Chrome으로 주소 열기 → 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
- 홈 화면에 추가한 뒤 그 아이콘으로 열어서 기록을 시작하세요.

기록은 사용하는 휴대폰 안에만 저장되고 어디로도 전송되지 않습니다.

## 파일

- `index.html`: 앱 본체(화면과 규칙 계산). 규칙 숫자는 파일 안의 `RULES`만 고치면 됩니다.
- `manifest.webmanifest`, `icons/`: 홈 화면 아이콘과 이름
- `sw.js`: 인터넷이 약한 곳에서도 열리도록 앱 파일을 기기에 보관
- `dev/test.mjs`: 규칙 계산 테스트. `node dev/test.mjs`로 실행합니다.
